# ReadFinch 设计与参考

0.2.1 在此基础上补充独立的 OCR 取词入口，详见 [触发流程](OCR.md)。可选文字直接进入动作；不可选文字通过显式框选、识别与校对后进入同一动作卡片。无选区引导、OCR 等待/空结果/校对和取消恢复的实际截图位于 `screenshots/v0.2.1/`。

工作发生在正在阅读或编辑的应用里：选择文字 → 鼠标旁工具条 → 对应动作浮窗。ReadFinch 主窗口承载设置与本地笔记。0.1.x 的工作台、主结果区和全局底部状态栏已移除。

## 0.6.0 的指令与笔记

设置采用陪读蛙的指令列表与就地编辑器。默认三条内置指令为词典、长难句分析和写作改进。图标选择器的 30 个常用项及其顺序来自 `icon-field-options.ts`，更多图标按三套本地图标集搜索。模型选择器贴着字段显示候选，自定义输入单独切换。

笔记沿用「在完成的指令结果上手动收藏」的流程。桌面端按指令选定的笔记本保存原文和结构化结果，阅读页只读取本机 SQLite。完整选区外的材料由用户在展开的原文里补充。

## 已对齐的工作浮窗

| 项目 | 实现 |
| --- | --- |
| 工具条 | 翻译、朗读、词典、润色与更多动作；只显示图标，靠近鼠标，无主应用导航 |
| 外框 | 默认宽 500 DIP，最小 320 × 180，10 px 圆角，细边框、阴影，内容增高后滚动 |
| 标题与底栏 | 44 px 高，横向 16 px 间距；动作标题、目标语言、固定和关闭；底栏为提供商、设置与重新生成。补充说明随原文展开 |
| 原文 | 14 px / 20 px，灰色文字，默认三行，展开后可滚动、复制、朗读 |
| 翻译 | 直接显示正文与复制、朗读；流式、取消、错误和重试保留在同一卡片 |
| 词典 | AZ 书本图标，20 px 词条、音标、斜体词性、级别标签、分隔线、粗体释义、例句和缩进译文 |
| 润色 | 同源彩色编辑图标、场景、原句彩色标注、悬停修改说明、答案/改后文本切换、解释与差异对照 |
| 图标 | 与参考相同的 Streamline Color、Remix Icon 和 Tabler 公开图标集，全部本地打包 |
| 主题 | 浅色白底；深色 #171717 卡片、浅色文字、灰色边框；选择跟随系统时订阅 nativeTheme 更新 |

工具条不激活输入焦点。普通结果窗失焦收起；固定后可在其他应用继续操作。窗口支持拖动、调整尺寸与 Esc 收起。新选区替换当前会话并取消旧任务，固定状态与几何位置保留。坐标统一使用 Electron DIP，避免 Windows 125% 缩放时因重复换算导致窗口越变越宽。

原文、模型凭据和图片不会因显示浮窗而自动发往服务。点击动作或按动作快捷键才发起对应请求。

## 快捷键

参考 [Read Frog 官方快捷键文档](https://www.readfrog.app/en/docs/shortcuts) 的选区翻译 `Alt+T` 与录入方式；同版本公开源码 `src/utils/constants/custom-action.ts` 为词典定义 `Alt+Shift+D`、润色定义 `Alt+Shift+W`。ReadFinch 新配置采用这三个默认值，旧配置保留原来的翻译组合键。菜单、OCR、剪贴板分别保留独立入口。

浏览器扩展在网页中监听按键，桌面应用使用 Electron 全局注册。按动作快捷键时重新读取前台选区，忽略鼠标缓存；读取失败进入无选区引导，不自动使用剪贴板或截图。暂停自动浮标不影响显式快捷键。OCR 或其他文字浮窗有焦点时，动作使用该浮窗当前编辑后的文本；设置中的文字输入不触发动作。长按的短间隔回调被抑制，新的动作会淘汰迟到的旧选区读取。

快捷键设置使用紧凑行和只读录入控件，深浅主题沿用系统配色；点击/键盘聚焦后录入，完成自动保存。录入期间暂停全局快捷键；Esc 取消、Backspace/Delete 清空，另提供可访问的清空按钮。自定义动作编辑器使用同一控件；冲突在当前设置区域显示。实际截图见 `screenshots/v0.2.2/`。

## 服务商与 OCR 配置（0.3.0）

继续检查 Read Frog 的 `src/utils/constants/providers.ts`、`api-providers/providers-config/add-provider-dialog.tsx`、`provider-editor.tsx` 与 `provider-config-form/provider-url-field.tsx`。沿用“服务商目录 → 账户配置 → 功能使用的模型”的结构：点击添加后从六个预设或自定义接口开始，左侧服务商列表、右侧编辑地址/密钥/模型。每个服务商只保留一份凭据；文字和 OCR 分别指定模型。

使用随包的字母标记与功能图标，不远程加载 logo；所有表单、目录弹窗、选中态与错误提示随深浅/系统主题变化。弹窗支持键盘焦点循环、Esc 关闭和焦点返回。0.3.0 当时采用手动 ID 与接口发现；0.4.0 补充下述内置候选和用途入口。

OCR 页面突出默认内置离线选项；服务商选项只引用已配置的视觉模型。使用样例图片检测真实图片请求，不将文字连接成功当作视觉验证。配置管理合并 WebDAV 与导入、导出、备份，不重复增加导航入口。截图见 `screenshots/v0.3/`。

## 模型与用途（0.4.0）

根据模型目录和功能分配组件重新组织配置。一个账户只填写一次地址与密钥，在“模型与用途”标签下管理多个模型。每张模型卡片直接选择默认动作模型、翻译、词典、润色或 OCR；其他动作折叠在“更多动作”。各功能在不同模型之间互斥分配，同一模型可服务多项功能。未指定的动作跟随默认，明确指定后保持独立。

统一搜索弹层提供内置目录、接口发现、已有配置和自定义 ID，实时过滤并支持方向键/Enter/Esc。OCR 排除已知纯文本候选，标记图片能力与未知项；操作不会直接调用识别。账户配置与用途配置使用同页标签，减少重复字段。动作列表显示模型与账户；浮窗支持临时切换，仍保留已保存的绑定。截图在 `screenshots/v0.4/`，目录核查和具体行为见 [MODELS.md](MODELS.md)。

## 0.5.0 的划词工具栏与提供商配置

在原选区旁展开更多菜单，图钉控制固定状态，拖动可改变动作与朗读的顺序。关闭按钮在鼠标移入或键盘聚焦时出现。临近屏幕边缘时菜单改变展开方向，工具栏保持在原位。桌面停用范围按当前应用名、一小时或全局计算。

API 提供商页沿用陪读蛙的分组图标目录、账户列表、功能数量徽标和单表单布局。每个提供商对应一个模型，复制账户即可配置另一个。OCR 与各动作复用同一提供商选择器。界面语言与翻译语言分别设置，快捷键单独成页。

## 设置

44 px 系统式标题栏、可响应窗口宽度的侧栏、六个配置页面（通用、API 提供商、截图识别、动作、快捷键、配置管理）；状态仅在侧栏下方显示。采用中性灰与系统感蓝色强调色，深浅模式分别定义背景、文字、边框和表单状态。

普通设置 400 ms 防抖保存；API Key 650 ms、WebDAV 500 ms。主题即时生效。界面显示保存中、已保存或待完善，不设“保存设置”按钮。不完整的地址等保留为草稿，不能覆盖有效配置。保存回执与仍在输入的内容合并，避免慢请求回写旧值。动作编辑器关闭前提交当前有效内容。

应用采用 ReadFinch 小雀图标，包含彩色、单色及托盘正常/暂停资产，见 [当前品牌说明](brand/READFINCH.md)。划词工具栏继续使用功能图标。早期品牌探索作为历史记录保留。
