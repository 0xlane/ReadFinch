# ReadFinch 交互设计

工作发生在用户正在阅读或编辑的应用里：选择文字 → 鼠标旁划词工具栏 → 翻译、词典或指令结果。应用主窗口用于配置，独立的本地笔记库用于浏览已保存内容。

## 划词与截图

- 工具栏提供翻译、朗读、词典、长难句分析与写作改进。更多指令支持悬停展开、固定和排序；关闭菜单提供暂停一小时、在当前应用禁用和全局禁用。
- 选区快捷键可直接运行指定指令。主界面录入快捷键时暂停全局监听，冲突即时显示。
- 无法选择的文字通过显式框选或图片导入进入 OCR。默认离线识别，远程识别先展示图片及目标提供商，随后由用户发送。
- 截图按原始设备像素显示，框选区保持清晰；取消不会启动识别。详见 [OCR 流程](OCR.md)。

## 结果与笔记

译文和结构化字段随流式回答逐步显示。词典、长难句和写作改进采用各自的卡片版式；分析可展开或收起，用户选择不会被后续流式更新覆盖。

自定义指令提供提示词、图标、输出 Schema、HTML + Liquid 版式、示例数据和笔记字段映射。编辑与预览共用实际结果渲染器，支持深浅主题和不同宽度。

结果书签保存到选定的本地笔记库；未连接时可按输出字段创建库。笔记记录原文、结果及当时的字段与版式，删除指令后仍可查看。猜你想存会提供可勾选的词条建议。

## 设置

设置跟随系统深浅色，也可手动选择。界面语言默认跟随系统；翻译目标语言独立配置。所有普通设置自动保存，无效草稿保留并提示完善。

每个 API 提供商使用一个模型。预设填好默认模型，输入框原位展开内置或发现的候选，也可直接填写自定义 ID。同一页分配指令、OCR、语言检测和语音用途。高级选项包含温度、请求头、代理、流式与超时。[提供商说明](MODELS.md)

文本转语音同时支持系统离线声音与在线语音提供商。按语言配置声音、兜底声音、语速、音高和音量，提供试听。

配置管理合并导入导出与 WebDAV。账号密钥与请求头留在本机加密存储；本地笔记正文不进入配置同步。

## 应用标识

应用、安装器、启动项、数据目录和原生辅助程序采用同一 ReadFinch 命名体系，不使用其他产品名作为运行别名。[品牌与标识](brand/READFINCH.md)
