## 笔记存储边界

本地库和列分别使用稳定的 ID。指令的连接保存目标来源、库 ID，以及输出字段 ID 到目标列 ID 的映射。笔记保留写入时的字段与结果快照，删除指令后仍可重读。库目录与映射随配置迁移，正文仅存本机 SQLite。

未来的远程连接可以使用独立账户或后端标识作为来源。当前版本只写入来源为 local 的目标。无法识别的连接会保留并提示重新选择，可以避免同名的本地库接收到远程目标的数据。独立的「本地笔记库」页面只查询本机内容。

## 桌面场景的取舍

桌面选区、显式补充的上下文和用户框选的 OCR 区域是不同输入。浏览器扩展可以读取网页段落、标题和整页信息，桌面版不采集其他窗口的整页内容。托盘暂停使用当前应用范围，截图与快捷键可以独立使用。在线账号、远程笔记、卡片学习和浏览器页面级工具属于其他范围。
