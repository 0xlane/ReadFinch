# ReadFinch 1.2.5 · 伴读雀

- 修复写作改进处理包含冒号、命令和报错信息的文本时，原文与改后内容可能缺失并出现版式过滤提示的问题。
- 改善写作改进的修改策略：优先调整需要改进的表达，保留粘贴的命令、日志、诊断提示及其格式。
- 调整写作结果排版，原文标注在前，场合与总评紧随其后；改后文本使用独立卡片，支持修改高亮和一键复制。
- 等待回答时显示动态占位行，仅在改后内容到达后显示对应标题与卡片。
- 更新未自定义的内置写作指令，同时保留用户修改过的提示词。

## English

- Fixed missing original and revised text, and misleading layout warnings, when writing input contains colons, commands, or error messages.
- Improved writing feedback to focus on meaningful edits while preserving pasted commands, logs, diagnostic hints, and formatting.
- Refined the result layout with annotated source text, compact context and summary, and a separate revision card with change highlights and a copy button.
- Added an animated placeholder while waiting; the revision heading now appears only when revised content arrives.
- Updated untouched built-in writing prompts while preserving user-customized prompts.
