# ReadFinch 1.1.0 · 伴读雀

This release improves provider configuration, screenshot recognition and text to speech.

- Switching OCR providers now recognizes the current image automatically. Results from cancelled or replaced requests cannot overwrite the latest result.
- A fetched model list shows only models returned by that provider. Choosing a model from the list keeps custom model input off.
- Model choices distinguish text, image-capable and speech models. Feature assignments only offer compatible providers, with manual capability settings for custom models.
- Adds Xiaomi MiMo text and speech presets, MiMo speech synthesis, provider-specific voice choices and optional voice instructions alongside OpenAI-compatible speech and system offline voices.
- Simplifies advanced settings by removing the API-key requirement and streaming switches. Custom compatible endpoints can work without a key; text responses stream by default, with a fallback for endpoints that explicitly reject streaming.
- Improves setup guidance and documentation across all eight README languages.

Existing settings, credentials and local notebooks are preserved. Automatic updates can be managed in **About**. Windows installers and Linux AppImages support installation on exit; Windows portable, macOS and Linux DEB packages use manual installation.

本次更新改进了提供商配置、截图识别和文本转语音体验。

- 切换 OCR 提供商后自动重新识别当前图片；取消或被替换的请求不会覆盖新结果。
- 获取模型列表后只显示该提供商返回的模型；从列表选择模型不会自动勾选自定义模型 ID。
- 清晰区分文本、图片输入和语音模型，按功能筛选适用提供商，也可手动设置自定义模型的能力。
- 新增小米 MiMo 文本与语音预设、语音合成适配、对应音色与可选朗读风格，同时保留 OpenAI 兼容语音和系统离线语音。
- 简化高级选项，移除「需要 API Key」和「流式输出」开关。自定义兼容接口可无密钥使用；文本默认流式输出，接口明确拒绝流式时自动回退。
- 完善八种语言 README 和上手说明。

原有配置、凭据和本地笔记会保留。可在「关于」页管理自动更新；Windows 安装版和 Linux AppImage 支持退出时安装，Windows 便携版、macOS 和 Linux DEB 需要手动安装。
