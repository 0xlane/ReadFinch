# ReadFinch 1.2.1 · 伴读雀

- Fetched model lists are now saved on this device for each provider and connection. After a restart, the model picker shows the last successful list, even when the provider is unreachable. A failed refresh keeps that list, and a successful empty response clears the choices.
- **API Providers** reopens the provider you last viewed. If an earlier version lost a model list, fetch it once after upgrading.

---

- 每个提供商及其连接配置都会在本机保存获取到的模型列表。重启后，即使暂时连不上提供商，仍可查看上次的候选模型。刷新失败会保留原列表，接口成功返回空列表时会清空候选项。
- 再次打开「API 提供商」会回到上次查看的提供商。如果旧版本已经丢失了列表，升级后重新获取一次即可。
