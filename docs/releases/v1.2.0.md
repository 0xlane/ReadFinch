# ReadFinch 1.2.0 · 伴读雀

- **Model details.** Selecting a model now shows its capabilities, name and context window when available. ReadFinch matches the provider’s model ID against Models.dev and OpenRouter on your device. Unknown or ambiguous IDs default to text. For a private deployment, you can set its capabilities under **Advanced options**.
- **Translation languages.** Choose a source language or leave it on **Auto-detect**. On first use, ReadFinch selects a target from your system language preferences and saves it. Translations, dictionary definitions and writing feedback use that target. Upgrading preserves your selected target and turns the former **Follow app language** choice into a saved language.
- **Windows display language.** **Appearance → Interface language → Follow system** now follows your Windows display language even when another language is first in your preferred list. Switching the interface language preserves your translation preferences.

---

- **模型信息**。选择模型后，输入框下方会显示模型能力，以及公开目录收录的名称和上下文长度。伴读雀在本机按模型 ID 匹配 Models.dev 和 OpenRouter。未收录或有重名歧义时，默认按文本模型使用。私有部署可在「高级选项」中手动指定能力。
- **翻译语言**。源语言可固定，也可自动检测。目标语言在首次使用时按系统语言偏好选定并保存，译文、词典释义和写作建议共用该语言。升级会保留手动选择的目标语言，原先选择「跟随应用语言」的配置会保存为当时使用的语言。
- **Windows 显示语言**。「外观 → 界面语言 → 跟随系统」现在会采用 Windows 的显示语言。即使首选语言列表把中文排在第一位，英文 Windows 也会显示英文界面。切换界面语言会保留已选的翻译语言。
