# ReadFinch 1.0.0 · 伴读雀

The first stable release of ReadFinch, a desktop reading and writing companion.

- Select text to translate, look up words, understand sentences, or improve writing.
- Stream answers and available reasoning summaries beside your original text.
- Capture otherwise unselectable text with bundled offline OCR.
- Configure your own AI providers, custom commands, speech voices, and local notebooks.
- Find project information, feedback links, and update controls together in About.
- Get signed, verified updates from GitHub Releases, with automatic gh-proxy fallback when the direct connection fails.

Automatic updates are enabled by default. Windows installers and Linux AppImages install downloaded updates when the app quits; a restart button is also available. Portable Windows packages, macOS bundles, and Linux DEB packages offer verified downloads for manual installation. Your settings, credentials, and local notebooks stay in their existing location.

Choose the Windows **setup.exe** for an installed app with automatic updates. The **portable.exe** runs without installation. macOS downloads are available for **arm64** (Apple silicon) and **x64** (Intel). Linux offers **AppImage** and **DEB** packages for x64.

The Windows packages do not yet have an Authenticode certificate. macOS packages use ad-hoc signatures and are not notarized with an Apple Developer certificate. Download only from this repository. The in-app updater verifies the release manifest's Ed25519 signature and each package's SHA-512 digest, including downloads through gh-proxy.
