# ReadFinch 1.2.3 · 伴读雀

- 新增输入翻译快捷键：macOS 默认 `⌥A`，打开即可输入，Enter 翻译、Shift+Enter 换行；划词翻译默认 `⌥D`，截图 OCR 默认 `⇧⌥S`。已有自定义快捷键会保留。
- 置顶浮窗独立保留内容和正在执行的任务，新请求打开另一扇浮窗。
- 改善浮窗在鼠标附近的定位，修复短内容靠近屏幕底部时距离鼠标过远，以及重新打开时高度未恢复的问题。
- 改善 macOS 聊天应用的鼠标划词兼容性；键盘选区只响应手动快捷键。
- macOS 设置窗口改用系统原生的关闭、最小化和全屏按钮，结果浮窗也采用原生关闭控件。
- 修复密钥保存后无法查看的问题，现在可以显示已保存的密钥，重启后继续使用。
- 缺少划词或截图权限时，明确说明原因并提供系统设置入口；开启权限后自动恢复连接。
- macOS 的已授权状态可随后续版本升级保留，减少反复授权。

从旧版首次升级到本版本时，macOS 可能需要重新允许一次辅助功能和录屏权限，请按应用中的提示操作。
