# ReadFinch 1.2.8 · 伴读雀

- macOS 新增“重启更新”：下载完成后，可从关于页面或托盘“重启应用”安装更新并重新打开应用。准备失败时保留当前应用，启动请求失败时尝试恢复原版本。
- macOS 更新继续校验安装包及版本，沿用固定签名身份；应用位于只读位置时保留手动安装方式。
- 完善 Windows 划词工具栏的手势取消逻辑：键盘打断拖选或点击时，清理未完成手势、连击记录及过期读取，避免后续鼠标事件误触发工具栏。正常鼠标划词及快捷键取词保持可用。
- 参考 Bob 统一默认快捷键：输入翻译 `Alt+A`、划词翻译 `Alt+D`、截图 OCR `Alt+Shift+S`（macOS 中 Alt 对应 Option）。升级时仅迁移未冲突的旧默认值，保留自定义和已清空的快捷键。

macOS 旧版客户端需手动安装本版本一次，之后可在应用内使用“重启更新”。

## English

- Added **Restart to update** on macOS. Install a downloaded update from About or the tray's **Restart app** command, then reopen the application. Preparation failures preserve the running app; a failed launch request attempts to restore the previous version.
- macOS updates verify the package and version and retain the fixed signing identity. Applications in read-only locations retain manual installation.
- Improved Windows selection-gesture cancellation: keyboard input discards unfinished drags, click history, and stale reads so later pointer events cannot accidentally reopen the toolbar. Normal mouse selections and direct selection shortcuts remain available.
- Aligned default shortcuts with Bob: `Alt+A` for input translation, `Alt+D` for selection translation, and `Alt+Shift+S` for screenshot OCR (Option on macOS). Upgrades migrate only unoccupied legacy defaults and preserve custom or cleared bindings.

Older macOS clients need one manual installation of this version to enable subsequent in-app restart updates.
