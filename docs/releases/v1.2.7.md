# ReadFinch 1.2.7 · 伴读雀

- 修复 Windows 划词工具栏和更多菜单在某些焦点状态下点击无响应的问题，包括“写作改进”等指令。工具栏弹出时保留原应用焦点，点击时可正常交互。
- 调整 Windows 选词触发逻辑：拖选、双击和 Shift 点击选词可显示工具栏；键盘全选或应用自动选择文字不再弹出工具栏，仍可使用快捷键直接调用。
- 保留选词时的文本快照，改善鼠标移入工具栏及展开菜单时的稳定性，并适配屏幕缩放。
- 修复原应用置顶时，工具栏或展开菜单可能被压在其下方的问题。
- 在托盘右键菜单中新增“重启应用”。若更新已下载，将由更新安装器完成重启。

## English

- Fixed unresponsive Windows selection toolbar and expanded-menu buttons in certain focus states, including writing improvement. Showing the toolbar preserves the source application's focus; clicking its controls works normally.
- Refined Windows selection triggers: dragging, double-clicking, and Shift-clicking can show the toolbar. Keyboard-only and programmatic selections no longer open it automatically; direct selection shortcuts remain available.
- Preserved the selected-text snapshot while moving into the toolbar and its menu, with screen-scaling-aware hit regions.
- Fixed the toolbar or its expanded menu appearing behind an always-on-top source application.
- Added **Restart app** to the tray menu. When an update is ready, its installer handles the restart.
