# ReadFinch 1.2.6 · 伴读雀

- 修复 Windows 划词助手超时后无法自行恢复的问题。助手卡死或异常退出时会自动重建，连续失败时逐步延长重试间隔。
- 为普通编辑框的选区读取和文字替换增加超时保护，避免目标应用无响应时一直阻塞划词服务。恢复过程中清理失效选区，不自动重复执行文字替换。
- 新增划词诊断日志，记录故障相关应用、读取阶段、耗时和助手恢复过程，日志总量限制约 1.5 MB。
- 在「关于」页面新增「导出诊断日志」。日志仅保存在本机，不记录选中文字、剪贴板内容或 API 密钥，不自动上传。
- 改善服务重连状态的提示，并适配中英文及深浅色界面。

## English

- Fixed Windows selection helpers remaining unavailable after a timeout. Stalled or unexpectedly terminated helpers now restart automatically, with increasing delays after repeated failures.
- Added timeouts to standard edit-control selection reads and text replacement. Recovery clears stale selections and never automatically replays a replacement command.
- Added bounded local selection diagnostics covering the affected app, reading stage, timing, and helper recovery. Logs use approximately 1.5 MB at most.
- Added **Export diagnostic logs** to **About**. Logs stay on the device and exclude selected text, clipboard contents, and API keys. Nothing is uploaded automatically.
- Improved reconnection status messages, with Chinese and English support and matching light and dark styling.
