# ReadFinch 1.2.2 · 伴读雀

- **Windows selection toolbar.** The toolbar opens at its final size and stays on the display where you selected text. Near the right or bottom edge it opens to the left or above the pointer. This addresses flicker and a toolbar that could appear as a thin line on multi-monitor desktops.
- **macOS selection.** Select a repeated word elsewhere in a document and the toolbar follows the new selection. Keyboard selections use the text position when the pointer is on another display. Web views that expose selected text through accessibility text markers are now supported. The toolbar can appear over full-screen apps, and granting Accessibility permission takes effect while ReadFinch is running.
- **IntelliJ IDEA and Swing.** ReadFinch can read editor selections through Java Access Bridge, including when a tool window has keyboard focus. If a Java runtime has accessibility disabled, the selection shortcut opens setup instructions. [IDEA setup](https://github.com/0xlane/ReadFinch/blob/v1.2.2/docs/PLATFORMS.md#在-intellij-idea-编辑器中划词)
- **API providers.** You can test a connection and fetch models from gateways that accept requests without an API key. Test errors now appear in a dismissible notification. Advanced settings support provider-specific JSON options, and model lookup recognizes more vendor-prefixed IDs.
- **Translation panel.** The provider picker shows the provider name. Clicking the pencil focuses the editor so you can type immediately.

---

- **Windows 划词工具栏。** 工具栏会在选区所在的显示器上按最终尺寸打开，靠近屏幕右边缘或下边缘时会自动向左或向上避让。此项修复针对多屏环境下的闪烁和工具栏只显示一条横线的问题。
- **macOS 划词。** 在同一文档里选中另一处相同单词，工具栏会跟到新位置。使用键盘选词且鼠标停在另一块屏幕时，工具栏会出现在选区旁。现已支持通过辅助功能文本标记读取网页选区，工具栏也能在全屏应用上显示。运行中授予辅助功能权限后即可继续划词。
- **IntelliJ IDEA 与 Swing。** 伴读雀可以通过 Java Access Bridge 读取代码编辑器中的选区。工具窗口持有键盘焦点时，也可以读取鼠标下的编辑器选区。若运行时尚未开启无障碍支持，按划词快捷键可查看设置方法。[查看 IDEA 设置说明](https://github.com/0xlane/ReadFinch/blob/v1.2.2/docs/PLATFORMS.md#在-intellij-idea-编辑器中划词)
- **API 提供商。** 免鉴权网关可以直接测试连接和获取模型列表。测试错误会在可关闭的通知中展示。高级设置支持提供商专用 JSON 参数，模型识别也支持更多带厂商前缀的 ID。
- **翻译浮窗。** 提供商选择器显示提供商名称。点击铅笔图标会直接进入编辑，可立即输入。
